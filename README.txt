HOW TO EDIT QUICKLY
1. Open the files in any code editor.
2. Edit text inside the /content JSON files.
3. Replace images inside /assets/images.
4. Keep the same file names, or update the JSON paths if you rename images.

HOW TO USE THE ADMIN PANEL
This package includes a real static CMS setup using Decap CMS.
To make /admin work online:
1. Upload the whole site to a GitHub repository.
2. Deploy that repository to Netlify.
3. In Netlify, enable Identity and Git Gateway.
4. Visit /admin on your live site.
5. Log in and edit content and images there.

LOCAL TESTING
Because the site loads JSON files, use a local server instead of opening files directly.
Example:
- VS Code Live Server
- or Python: python3 -m http.server 8000

Then open:
http://localhost:8000/
