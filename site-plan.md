# The Rok Group Website Plan

## Chosen direction

The redesign will follow a **British atelier construction** approach shaped by the user’s visual references. The website should feel more like an architectural residential portfolio than a generic contractor brochure. The tone will be calm, premium, and grounded in workmanship, with a stronger emphasis on finished spaces, careful detailing, and trust-building content.

## Visual principles

The visual system will use **warm stone neutrals**, **deep slate-blue accents**, **soft off-white backgrounds**, and **oak-inspired warmth**. Typography will combine a bold condensed display face for headings with a more refined readable sans serif for body content. Layouts will be intentionally asymmetric, with large image fields, offset text blocks, and editorial spacing rather than repetitive centred sections.

The user’s reference images indicate the right emotional territory: contemporary rear extensions, light-filled interiors, tactile joinery details, and controlled site management. These should shape the final experience more strongly than the current van-led imagery on the live site.

## Planned homepage structure

| Section | Purpose | Key content |
|---|---|---|
| Header | Establish brand and simple navigation | Logo wordmark, Home, Services, Projects, Areas, Contact, telephone, consultation CTA |

| Service areas | Reinforce local relevance | Sussex, Surrey, Kent, Greater London |
| Testimonial / trust strip | Increase confidence | Client quote, response promise, premium finish message |
| Contact section | Improve conversion | Consultation invitation, contact details, enquiry form-style CTA block |
| Footer | Support navigation and contact | Quick links, phone, email, service-area summary |

## Content positioning

The copy will shift away from generic construction language and become more specific to homeowners seeking well-managed residential building work. Messaging should communicate that Rok delivers **carefully managed builds**, **high-quality finishes**, and **clear client communication** across extensions, refurbishments, and bespoke new-build projects in the South East.

## Confirmed page set for full-site expansion

The expanded site will follow the main structure already implied by the homepage navigation and the live website audit. The core public pages to build next are **Home**, **Services**, **Projects**, **Process**, **Areas**, and **Contact**. This keeps the information architecture simple for homeowners while giving each major decision point a dedicated page.

| Page | Role in the user journey | Primary objective |
|---|---|---|
| Home | First impression and overview | Establish premium residential positioning and route visitors clearly |
| Services | Offer detail | Explain extensions, renovations, new builds, and project management more convincingly |
| Projects | Proof and inspiration | Show finished outcomes, design quality, and workmanship standards |
| Process | Reassurance | Explain how projects are managed from first discussion to handover |
| Areas | Local relevance | Reinforce South East coverage and support location-based trust/SEO |
| Contact | Conversion | Make it easy to start an enquiry by phone, email, or message |


## Route and layout architecture for the expanded site

The full-site build will use a shared public-facing layout so that every page inherits the same header, footer, navigation structure, typography system, and contact pathways. This is important because the value of the redesign is not only visual polish on individual pages, but consistency across the whole journey from first visit to enquiry.

| Route | Planned component purpose | Notes |
|---|---|---|
| `/` | Homepage | Keep the existing editorial landing page as the brand anchor |
| `/services` | Service overview page | Expand core offers into richer residential messaging and service cards |
| `/projects` | Project showcase page | Use portfolio-led storytelling, outcomes, and featured categories |
| `/process` | Delivery process page | Explain consultation, planning, build, and handover in more detail |
| `/areas` | Coverage page | Present South East service regions with stronger local trust framing |
| `/contact` | Contact page | Create a dedicated, cleaner enquiry page in addition to homepage contact CTA |

The shared layout should include the following structural elements on every page: a persistent header with route-aware navigation, a footer with core links and contact details, and reusable section styling that preserves the editorial British atelier design language. Each page should have a distinctive hero and content focus, but all pages must feel like they belong to the same premium residential brand.
